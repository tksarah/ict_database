# DBラボ：学園祭データベース

専門学生が、ブラウザ内で動く実際のSQLiteを使ってリレーショナル
データベースの基礎を体験するWebAppです。登録やサーバー側データベースは
使用しません。

## 学習内容

1. 表の構造：行・列・セル、`INTEGER` / `TEXT`
2. `CREATE`：主キーを持つ店舗テーブル
3. `INSERT`：主キーと外部キーの関連付け
4. `SELECT`：全件取得と列指定
5. 発展：`WHERE`による条件検索

各ミッションには3段階のヒントと確認問題があります。自由SQLラボは
`CREATE` / `INSERT` / `SELECT`を1文ずつ実行できます。

## 開発

Node.js 22.13以上を使用します。

```bash
npm install
npm run dev
npm test
```

`npm test`は本番ビルド、SQLiteの操作、エラー、レスポンシブ規則、
検索除外メタデータを検証します。

## データの扱い

- SQLiteデータベースはページを開いている間だけブラウザ内に存在します。
- 進捗はバージョン付きで端末の`localStorage`に保存します。
- 氏名・メールアドレス・成績などの個人情報は取得しません。
- 教材PDFの本文・スクリーンショット・固有図表は収録していません。
